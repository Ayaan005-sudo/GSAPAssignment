# 🚀 Scroll-Driven Hero Section Animation

This project is a scroll-based animated hero section built using **React**, **Tailwind CSS**, and **GSAP ScrollTrigger**.
It features a space-themed layout where a rocket launches upward as the user scrolls through the page.

The goal of this project was to demonstrate **frontend animation skills**, **scroll-triggered interactions**, and **responsive design techniques**.

---

## ✨ Features

* Smooth **hero section entrance animation**
* **Scroll-triggered rocket launch animation**
* **Responsive design** for different screen sizes
* **Tailwind CSS styling**
* Clean component structure using **React**
* **GSAP + ScrollTrigger** for high-performance animations

---

## 🛠 Tech Stack

* React
* Tailwind CSS
* Bootstrap
* GSAP
* GSAP ScrollTrigger
* Vite
* Html
